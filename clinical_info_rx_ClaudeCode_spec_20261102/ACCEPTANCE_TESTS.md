# 受け入れテスト一覧

## 9. 受け入れテスト（必須シナリオ）

| ID | Given / When / Then |
|---|---|
| `T01` | 患者がQRを表示→医療者が読む→患者が拒否→患者の履歴APIは403で拒否される |
| `T02` | 患者承認→医療者が学習履歴と質問を閲覧・教材を処方できる |
| `T03` | 5分経過したQR・承認済みの使い終わったQRは再使用できない |
| `T04` | 60分経過・患者が共有停止→医療者の新しい閲覧/更新APIが拒否される |
| `T05` | 病院Aの認証済み職員が病院B専用の未共有教材/原資料を取得できない |
| `T06` | 共通教材は作成者本人による承認を拒否し、別承認者が承認できる |
| `T07` | 病院独自教材は作成者に承認権限があれば自己承認できる |
| `T08` | AI送信不可の資料では教材生成APIが呼び出されない |
| `T09` | AI生成教材は承認されるまで患者向けの処方候補に現れない |
| `T10` | 3択＋わからない：正解2、誤答1、わからない1→50点、内訳を区別して表示 |
| `T11` | 4問中2問で中断→再開は3問目、スコア未確定、過去の完了スコア維持 |
| `T12` | 再受験100点→現在の教材スコアが更新、初回挑戦の記録は保持 |
| `T13` | 1診察中の複数回処方は1宿題セット。同教材重複は1件に統合 |
| `T14` | 別診察で同教材を再処方→過去の進捗とスコアを引き継ぎ、強制再学習しない |
| `T15` | 次回診察開始→前回宿題のスコア/進捗を一度だけスナップショット化。その後の再学習でも不変 |
| `T16` | 患者が質問→医療者が確認済み/対応済みにし対応方法を記録→患者履歴に残る |
| `T17` | 医師画面は未確認の質問・誤答・未完了教材をスコアより優先して表示する |
| `T18` | 公開教材改訂→軽微改訂は再評価不要。実質改訂は旧新版を別評価 |
| `T19` | LINE/メール通知には病名・薬剤名・得点などの機微情報が含まれない |
| `T20` | 権限を持たない利用者による削除は拒否。原資料を削除する際に関連教材の依存関係が表示される |
| `T21` | 保存期間候補の期限到来では無断の原資料自動削除をしない。管理者に整理候補を通知する |
| `T22` | 同じ患者が別の病院で一時アクセス承認しても、従前の学習履歴は本人のアカウントに残る |



テストはUI操作だけでなく、期限切れ・患者拒否・病院またぎ・許諾違反のAPI拒否を自動化する。
