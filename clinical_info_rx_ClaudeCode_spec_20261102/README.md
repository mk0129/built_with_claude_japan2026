# Claude Code 引き継ぎパッケージ

**作成日：2026-11-02**

## ファイル

- `REQUIREMENTS.md`：総合要件定義書 v1.0（**最優先で読む**）
- `DECISIONS.md`：ユーザーが明示的に確定した要件と、まだ未合意の保存期間等の提案値
- `ACCEPTANCE_TESTS.md`：機能・セキュリティの受け入れテスト
- `CLAUDE.md`：Claude Code向け開発ルール
- `DESIGN_REFERENCE.png`：採用済みの水彩調ホームの**ビジュアル参照**（制作済みの実装素材であるとは限らない）

## 使い方

1. 新規GitHubリポジトリのルートへMarkdownファイルを配置。
2. デザイン参照画像は、配布権利と公開リポジトリ掲載可否が確認できるまでは非公開の参照資料として扱う。必要ならローカルに置き、Gitの追跡対象外にする。
3. `claude` を起動して `CLAUDE.md` の「初回指示」を送る。
4. **実患者データと実際の院内資料を公開リポジトリへ入れない。** ハッカソンでは架空患者・許諾済み資料のみ。

## 旧要件との関係

2026-11-01作成の旧マスター引き継ぎ書より、2026-11-02の詳細対話で確定した「情報処方＋理解確認」に特化した本パッケージを優先。旧資料はデザインの経緯・将来構想の参考として保持する。
