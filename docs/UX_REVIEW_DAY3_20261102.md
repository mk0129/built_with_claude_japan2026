## 3. 見つかった問題と改善

### 患者側

| 問題 | 改善 |
|---|---|
| クイズで回答後、選んだ答えと正解の色分けが効いていなかった（Tailwind v4 のレイヤー順で `.btn` の背景が `bg-*` に勝っていた） | コンポーネント CSS を `@layer components` に移し、選択肢専用の `btn-option` に「正解」「あなたの答え」の状態色とラベルを追加。回答後も薄くしない |
| 最後の問題に答えると解説を見る前に結果画面へ飛んだ | 「結果を見る」を押すまで解説を表示するよう変更 |
| 「わからない」が文字だけで押せるものに見えなかった | 破線枠のボタンにし、選択時は塗りつぶし |
| 「← ホームへ」「← 説明に戻る」「目次」のタップ領域が 16〜23px | 44px 以上の `tap-link` / ボタンに変更 |
| 文字サイズを変えられない | 「文字を大きく」切替（18px → 21px、端末に記憶）を学習・クイズ画面に追加 |
| スマホでホーム画面に横スクロールが出る | 装飾を `overflow-x: clip` で抑制 |
| 承認ダイアログの項目が 2 列で折り返し、読みにくい | 1 列の見出し + 値に変更。共有範囲に「他の病院の分も含みます」を明示 |
| 宿題セットの見出しと病院名が横並びで折り返す | 日付見出しの下に「病院 ・ 医療者」を表示 |
| 共有画面で一瞬 QR ボタンが出てから「共有中」に切り替わる | 共有中の確認が終わるまで「確認しています…」を表示 |
| クイズの進み具合が数字だけ | 問題数分の進捗バーを追加 |

### 医療者側

| 問題 | 改善 |
|---|---|
| 右パネルで「処方を確定する」が画面外になり、パネル内をスクロールしないと押せない | パネルを「ヘッダ / スクロールする本文 / 常に見える候補・確定」の 3 段構成に変更 |
| iPad 縦・スマホ幅ではパネルが本文の下に回り、開くと患者情報が見えない | 1024px 未満では画面下部のドロワーに変更。閉じていても候補数・処方済み数をバーで表示し、候補があれば「候補 n 件を処方する」をワンタップで実行可能 |
| 「外す」「再処方」が縦書きに折り返す | `whitespace-nowrap` と `shrink-0` |
| 検索結果が 0 件のとき何も出ない | 「該当する教材がありません」を表示 |
| 未完了教材の行が長く読みにくい | 教材名を太字、付帯情報を 2 行目に |
| ヘッダの残り時間・延長・終了が狭い幅で崩れる | 折り返し可能にし、ボタンを 44px 以上に |

### 基盤

| 問題 | 改善 |
|---|---|
| ローカル PGlite ソケットで同時リクエスト時に prepared statement が混線（`bind message supplies N parameters`） | 接続を 1 本に直列化し、名前付き prepared statement を使用（Supabase では従来どおり `prepare: false`） |
| `next build` 中にローカル DB のロックと競合 | ビルド時はインメモリ DB |
| リポジトリが iCloud 同期下の Desktop にあり、`.next/` に「 2」付きの重複ファイルが生成されて古い CSS が配信された | `.next` を削除して再生成。恒久策はリポジトリを iCloud 対象外（例: `~/dev/`）へ移すこと（未実施・要判断） |

## 4. 修正後の操作フロー

**患者（スマホ）**: ログイン → ホーム（次に読むしおりが最上部）→ 教材（目次・読み上げ・文字拡大・自動保存）→ 確認問題（1 問ずつ確定、解説、説明に戻る）→ 結果（点数は材料であって評価ではない旨）→ ふりかえり送信 → ホーム。中断してもホームの「続きから」で再開できる。

**医療者（iPad / PC）**: ログイン → 所属選択 → QR / 6桁コード → 承認待ち → ダッシュボード（未確認の質問 → 誤答 → 未完了 → スコア）。各項目の「関連教材を処方」「再処方」で候補に追加 → 「処方を確定する」。パネルは PC では右カラム、iPad 縦ではドロワー。

**30 秒以内の情報処方**: テンプレート「まとめて追加」→「処方を確定する」の 2 タップ、または誤答行の「再処方」→ 確定の 2 タップで完了する。

## 6. iPhone・iPad 実機で追加確認が必要な事項

- Safari の Web Speech API で日本語音声が選ばれるか、読み上げ中の画面遷移で止まるか（ヘッドレスでは音声が出ない）。
- iPad Safari でのカメラ QR 読取（HTTPS 必須。自己署名証明書や Vercel プレビュー URL で確認）。
- iOS でのフォント描画（BIZ UDPGothic の読み込みと太さ）、ホームインジケータと下部タブの重なり（`safe-area-inset`）。
- 画面下ドロワー（iPad 縦）がソフトキーボード表示時に隠れないか（検索入力時）。
- 高齢患者による実タップ試験: 選択肢ボタンの間隔、「わからない」の意味の伝わり方、文字拡大の発見しやすさ。
- 読み上げ速度（現在 0.9 倍）の妥当性。
