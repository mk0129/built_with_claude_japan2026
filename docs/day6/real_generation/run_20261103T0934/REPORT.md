### 画面 1: 薬を続けるときの約束
**要点**: 症状がなくても、自己判断で薬をやめずに続けましょう。

この治療は、目に見えないがん細胞が増えるのを抑え、再発のリスクを下げるために行います。症状がなくても続けることに意味があります。量を減らすことも、自己判断ではしないでください。

（くわしく）やめたいと感じたときは、その理由を担当医や薬剤師に伝えてください。飲み忘れに気づいても、2回分をまとめて飲まないでください。対応に迷うときは薬剤師に確認してください。

### 画面 2: すぐ連絡が必要な症状
**要点**: 血栓や不正出血が心配な症状があるときは、早めに病院へ連絡してください。

片方の足が急に腫れる・痛む、急に息苦しくなる、胸が痛むときは、血栓（血のかたまり）の可能性があります。この場合は、次の診察を待たずに連絡してください。タモキシフェンを飲んでいて不正出血があるときも、早めに連絡してください。

（くわしく）夜間や休日は、病院から案内された連絡先に電話してください。不正出血があるときは、早めに担当医に伝え、婦人科を受診してください。

### 画面 3: 使う前に相談すること
**要点**: ほかの薬やサプリメント、避妊のことは、事前に相談しましょう。

他の病院で薬をもらうときや、市販薬・サプリメントを使いたいときは、事前に担当医か薬剤師に相談してください。タモキシフェンの効果に影響する薬があるためです。治療中は妊娠を避ける必要があり、避妊はホルモンを含まない方法を選びます。

（くわしく）将来の妊娠を希望する方は、治療を始める前に担当医に相談してください。

### 画面 4: 副作用は相談してよい
**要点**: つらい症状や気持ちの変化は、我慢せずに相談してよいものです。

ほてり、発汗、のぼせは、どの薬でも起こりやすい症状です。多くは治療を続けるうちに軽くなりますが、つらいときは相談してください。気分の落ち込みや眠りにくさなど、気持ちの変化も相談の対象です。

（くわしく）アロマターゼ阻害薬では、関節の痛みやこわばりが起こることがあります。骨密度が下がりやすくなるため、定期的に骨密度の検査を行います。

### 画面 5: まとめ
**要点**: あなたの治療については、担当医の説明が優先されます。

この教材は一般的な説明です。治療の内容や期間は、一人ひとり異なります。わからないことや不安なことは、次の診察で遠慮なく質問してください。
