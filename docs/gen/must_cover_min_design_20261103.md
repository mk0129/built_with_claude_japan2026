# GEN-05 Must-cover items 最小構成の設計（2026-11-03）

目的: 「落としてはいけない内容」（受診・連絡の目安、禁止事項、中止してはいけない等）を、生成前に医療者が確定し、生成後に網羅を確認できるようにする。AI の判定だけで医学的妥当性を保証しない。
根拠事例: Day 5 C 方式で「不正出血時は婦人科を受診」（¶17）が落ち、クイズも緊急症状を問わなかった（GEN-01）。

## 1. 最小構成（マイグレーションなし。1.5 日）

| 段階 | 何をするか | 置き場所 | 変更ファイル |
|---|---|---|---|
| 1 生成前・抽出 | 構成案ジョブ（outline）の出力に `mustCoverCandidates[]` を追加。各項目: `text`（患者向け 1 文）, `kind`（緊急連絡／受診の目安／禁止／注意／事実）, `sourceRef`（段落の引用） | `aiGenerationJobs.outputPayload` | `ai-generation.ts`（`OutlineSchema` と `outlinePrompt`） |
| 2 生成前・確定 | 案を選ぶ画面で候補をチェックボックス表示。医療者が必須にする項目を確定し、追加入力もできる（引用は原資料から選ぶ）。確定した配列を generate ジョブの入力に含める | `aiGenerationJobs.inputPayload.mustCover` | `GeneratePanel.tsx`（案の下に「必須事項の確認」）、`createJob` の入力スキーマ |
| 3 生成 | `materialPrompt` に必須事項を列挙し「各項目を本文に必ず含め、可能なら確認問題でも扱う」。出力に `coverage[]`（`itemId`, `slides[]`, `questions[]`）を要求 | 出力は `outputPayload.coverage` | `ai-generation.ts` |
| 4 生成後・照合 | `validateMaterial` で各必須項目の `sourceRef.quote` が教材の `sourceRefs` に含まれるかを機械的に照合（正規化して包含判定）。未網羅は `validationWarnings` に「必須事項が未網羅: …」。Claude の `coverage` は参考表示にとどめる | `outputPayload.validationWarnings` | `ai-generation.ts` |
| 5 承認前 | 編集画面上段に「必須事項 n / N 網羅」と未網羅項目へのジャンプ。承認時に未網羅があれば理由の入力を必須にし、`reviewComment` と監査ログに残す（承認はブロックしない） | 既存 `reviewComment`, `audit_events` | `Editor.tsx`, `authoring.ts`（approve 時の理由） |

必要な新しい永続化は `inputPayload` / `outputPayload`（jsonb、既存）だけなので、スキーマ変更なしで実装できる。版の確定後に項目を見返す必要が出た時点で `material_versions.must_cover` に昇格させる（+0.5 日）。

## 2. 評価方法
- Day 5 の C 方式（¶17 欠落）を再現ケースにし、必須事項「不正出血は婦人科受診」「足の腫れ・息苦しさ・胸痛は連絡」を確定した上で再生成。網羅率（必須 N 件中、照合で一致した件数）を前後比較する。実 API 1 回あたり約 $0.05。
- 擬似生成モードでは候補 2 件を固定で返し、E2E で UI の導線だけ検証する。

## 4. やらないこと（完全実装との差）
- 項目のライブラリ化（施設共通の必須事項テンプレート）
- 版を跨いだ項目の履歴・差分
- Claude による網羅判定の自動採点（機械照合は引用の有無だけ。判断は医療者）

## 5. GEN-01〜03 のプロンプト変更案（未適用・要判断）
実 API での検証（約 $0.10）が必要なため、コードには入れていない。適用する場合は `SYSTEM` に次を追加する。
- GEN-01: 「原資料に受診・連絡・禁止の行動が書かれていれば、テーマの範囲内では省略せず本文に含め、できれば確認問題でも 1 問扱う」
- GEN-02: 「1 画面は 1 主題。別の章の内容を同じ画面に混ぜない」＋ 機械チェック（1 画面の出典 `section` が 2 つ以上なら警告）
- GEN-03: 「誤答は明らかな誤りではなく、患者が実際に誤解しやすい内容（症状がなければやめてよい／期間は全員同じ／市販薬なら相談不要）から作る。誤答にも原資料にない医学情報は入れない」
