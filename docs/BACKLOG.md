## 将来の改善（検討のみ）

### GEN-05 Must-cover items（必須内容）の事前確認と網羅性点検 — 最小構成は実装済み（上記）
1. **生成前**: 原資料から Claude が「必須内容の候補」（受診・連絡の目安、禁忌、中止してはいけない等）を抽出 → 医療者がチェックボックスで確定・追記。
2. **生成時**: 確定した必須内容をプロンプトに含め、各項目をどの画面・設問で扱ったかを `coverage` として出力させる。
3. **生成後**: 原資料の該当文が教材の source_refs に含まれるかを機械的に照合し、未網羅の必須内容があれば承認ボタンの前に警告（承認ブロックはせず、理由の記録を求める）。
4. 評価: Day 5 の C 方式（¶17 欠落）を再現ケースとして、網羅率を前後比較する。
- 見積: 2.5〜3 日（スキーマ・プロンプト・照合・UI）。優先は原資料の医学的確認と生成物の品質評価の後。
