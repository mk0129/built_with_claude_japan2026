## 各図に付ける情報

- `title`, `kind`, `learning_objective`（教材の学習目標の文）, `labels[]`（本文と同じ語）, `source_note`（原資料の該当箇所）, `status`, `reviewer`, `reviewed_at`。
- `alt`（スクリーンリーダー用の 1〜2 文）。
- 色は最大 3 色＋線色。正誤・重症度を色だけで示さない。

## 監修フロー（Day 4 の教材ガバナンスと統合）

1. 編集者が仕様（上表）を登録 → `draft`。
2. SVG を制作し、教材の該当画面に `figure_ref` で紐づけ → `pending_review`（患者画面では「模式図・監修待ち」表示）。
3. 承認者（病院教材は自組織の承認者、共通教材は運営の別人）が確認 → `approved`（表示は「監修済み・日付」）。
4. 医学的内容の変更は実質改訂として新版扱い（D19）。
