## 2. 文字

| 要素 | 患者 | 医療者 |
|---|---|---|
| 本文 | OS ゴシック（Hiragino Sans / BIZ UDPGothic）18px、行間 1.75。拡大時 21px | 14〜15px、行間 1.45 |
| 命題（ひとこと要約） | 19〜21px、太字。A×B では明朝（Hiragino Mincho ProN / Noto Serif JP）可 | — |
| 見出し h1 | 26px、見出し用に明朝可 | 20px ゴシック |
| 補助 | 14〜15px、`--p-ink-2` 以上のコントラスト | 12〜13px |
| ボタン | 18px 太字、最小高さ 56px | 14px 太字、最小高さ 40px |

- 英数字・単位は半角、「・」で区切る。略語（T/N/M 等）は患者画面で使わない。
- 21px 拡大、OS 文字拡大、200% ズームで折り返しを検証（Playwright で幅 375 / 390 / 430）。

## 3. 余白・形

- 画面左右 22px（患者）、カード内 18px。縦のリズムは 8px 基準（8 / 14 / 18 / 22 / 26）。
- 角丸: 主役カード 0〜4px（A）または 20px（B）。統合案は 12px。ボタンは 999px。
- 境界線 1px `--p-rule`。影は使わない（ドロワーのみ）。
- 1 画面の「面」は最大 2 つ（主役カード＋図）。残りは罫線と余白。

## 5. 図解ルール

1. 図は学習目標と 1 対 1。装飾のみの画像は置かない（教材冒頭のブロブと線画は撤去）。
2. 種類: 比較図（A と B）／順序図（治療の流れ）／構成図（要素の組み合わせ）／手順図（相談までの道筋）／場面図（生活上の注意）。
3. SVG で作り、ラベルは本文と同じ語を使う。比率が医学的に正確でない場合は「模式図」と明示。
4. すべての図に「監修待ち」または「監修済み（日付・監修者）」バッジと出典を表示。監修前の図を事実として扱わない。
5. 色は最大 3 色＋線色。正誤・重症度を色だけで伝えない。
6. 生成 AI 画像は使わない（権利・正確性）。写真は使わない。
7. 仕様は `ILLUSTRATION_SPECS.md` に 1 図 1 項目で管理する。

## 6. 文言・状態表示の統一

| 場面 | 統一案 |
|---|---|
| セット | 「◯月◯日の診察で届いた説明」 |
| 教材 | 「教材」（「しおり」はサービス名のみ） |
| 状態 | 未着手／途中（◯/◯ 画面）／確認問題の途中／読み終えた |
| 開始 | 読む・聞く／続きから読む／確認問題の続きから |
| 回答前 | 「ひとつ選んでください。わからないときは『わからない』を選べます」 |
| 回答後 | 「ポイント: …」を 1 文 → 正解 → 解説 → 「◯画面目を読み直す」 |
| 結果 | 今回確認できたこと／もう一度確認できるところ／次の診察で聞きたいこと |
| 正誤 | ✓ 確認できた／！ ちがう答えを選びました／？ 「わからない」と答えました |
| 点数 | 「点数をみる」の先に「正解 n / m 問、◯ 点。次の診察で先生と確認する材料です」 |
| 共有 | 「あなたが許可した 60 分だけ共有されます」「いつでも終了できます」 |

## 7. モーション・アクセシビリティ

- 遷移は 150ms 以下のフェード。正誤のアニメーションなし。`prefers-reduced-motion` で無効化。
- タップ領域 44px 以上、主ボタン 56px。ボタン間隔 8px 以上。
- 見出し構造 h1 → h2、`aria-live` は解説表示のみ。図は `role="img"` と `aria-label`。
- フォーカスリング 3px `--p-fig-wash`。
- 読み上げが使えない端末では AudioBar を「この端末では読み上げを使えません」に置換し、本文はそのまま。
