# 画像アセットの差し込み仕様と受け入れ基準（Phase A）

## 1. 配置先と命名

| 種別 | 置き場所 | 命名 | 公開条件 |
|---|---|---|---|
| 医学的図解 | `public/assets/medical/` | `med_001_breast_stage_anatomy.png`（`asset_id` 小文字＋主題） | 利用許諾と公開可否が確定し、`review_status = approved` のものだけ。承認前は非公開ストレージに保管 |
| 情緒的イラスト | `public/assets/editorial/` | `edi_001_home_window.png` | 利用許諾と公開可否が確定したもの |
| 作業中・原画 | リポジトリに入れない | — | Day 4 の原資料ストレージ（非公開）で管理 |

- 推奨原画 1536×1024（図解）、1024×1280（ホーム挿絵）。配信は幅 860px 程度（2 倍解像度で 430px 表示）に書き出し、PNG のまま透過を維持。容量目安 300KB 以下。
- `asset_id`, `version`, `filename` を `figure_assets` に登録してから配置する。

## 2. 納品時の自動検査（スクリプト化予定: `scripts/check-asset.mjs`）

- [ ] ピクセルサイズが仕様どおり（±2%）。
- [ ] アルファチャンネルあり。四隅と辺の中点の α が 0（透過）であること。
- [ ] 白ハローの検出: 不透明画素に隣接する半透明画素の平均輝度が 240 未満。
- [ ] 画像内の文字・数字・矢印は目視で確認（自動 OCR は参考値）。
- [ ] ファイル名と `asset_id` の一致、`version` の採番。

## 4. 画面での受け入れ基準

- [ ] 教材のファーストビュー（390×844）で、命題 1 文と図解（または placeholder）と「この図で確認すること」のラベルが見える。
- [ ] 図解を 1 画面に窮屈に収めない。収まらない場合は画面を分ける（画像を縮小しない）。
- [ ] ラベル・凡例・出典・監修バッジは HTML/SVG で、文字拡大・VoiceOver で読める。
- [ ] 患者モードで未承認の画像が表示されない（API レベルでも URL を返さない）。
- [ ] 医療者画面には水彩装飾を持ち込まない。
- [ ] `prefers-reduced-motion` で動きなし。

## 5. 本体 UI への適用前にオーナーへ確認する事項

1. **病期の本文**: 現行の原稿「しこりの大きさ、リンパ節への広がり、ほかの臓器への広がりの 3 つを組み合わせて決めます」は、MED-001 の注意（3 要素だけで一意に決まると断定しない）と整合させる必要がある。採用する分類体系と補足文（「ほかの検査情報や腫瘍の性質が関わることもあります」）を監修者に確認したい。
2. **MED-002 の分割**: 場面集 1 点で絵柄を検証した後、点滴／相談／病院／自宅の 4 点に分けて制作してよいか。
3. **ホーム挿絵の大きさ**: C2 モックでは右上 118×132px。もう少し大きく（ヘッダー全幅の帯）する案もあるが、情報を押し下げないことを優先した。
4. **図解がない教材の扱い**: CSV で「任意」「不要」とした画面は、図なし（命題＋本文＋くわしく）で公開してよいか。
5. **管理者プレビューの権限**: 編集者・承認者（D22）に限定し、一般医療者には未承認図を見せない方針でよいか。
6. **データ変更**: `figure_assets` / `figure_placements` の新規テーブルと `material_slides` への 2 列追加（null 可）を次フェーズで行ってよいか。
