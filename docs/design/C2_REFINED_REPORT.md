## 3. リスク

1. **本文と図の整合**: 現行原稿「3 つを組み合わせて決めます」は MED-001 の注意（3 要素だけで一意に決まると断定しない）と整合させる必要がある。補足文の採否を監修者に確認するまで「要医療者確認」のまま。
2. **画像の到着待ち**: 承認済み画像がない期間は全教材がプレースホルダー表示になる。フォールバック文は各画面の学習目標から書き起こす必要がある（CSV の `figure_meaning` を元にする）。
3. **ラベル座標の管理**: 画像ごとにアンカー％座標を手で決める運用。画像の差し替え（版更新）時に再調整が必要。
4. **データ変更**: `figure_assets` / `figure_placements` の新設と `material_slides` の 2 列追加は、承認後にマイグレーションを行う（既存ロジックに影響なし、列は null 可）。
