## 1. 画像の扱い

- 原画 `EDI-001_home_window_watercolor.png`（1122×1013、透過、1.3MB）は `docs/design/handoff_visual_v1/assets/` に保管。
- 配信用に幅 600px（600×541、412KB、透過維持）へ縮小し `public/assets/editorial/EDI-001.png` に配置。表示は最大 160px なので 2 倍解像度でも十分。
- `figure_assets` の EDI-001 に `filename / width / height` を登録し、`review_status = approved`。
- **装飾イラストと医学的図解の区別**: 現在の実装は両方とも `review_status = approved` かつ画像ありで表示する同じゲートを通る。ただし editorial は医学的監修の対象ではなく「権利・公開可否の確認」の意味で approved にする運用とし、シードも editorial のみ納品済みなら自動で approved にする（medical は納品済みでも監修プレビューからの承認が必要）。取り込みスクリプト `scripts/import-asset.mjs` の `--approve` も editorial だけに許可。

## 2. サイズ・配置の判断

| 案 | 寸法（390 / 430） | 所見 |
|---|---|---|
| 試作 1 | 117×105 / 118×106、ログアウトボタンの下 | 118px は原画の情景（窓辺・人物・花）が潰れて「サムネイル」に見える。ログアウトと縦に並ぶため右列が雑然とし、挨拶文の幅が約 55% に圧迫された |
| **採用案** | 148×134 / 160×144、見出しの右に単独配置。ログアウトは最下部へ | 挨拶・名前・一言と並ぶ高さになり、情景が読める。主役カードの開始位置は 390px で y≈220、主ボタンは y≈524（844 中）で**ファーストビュー内**。見出し・主ボタンとの重なりなし、横スクロールなし（`edi_audit.json`） |

- 幅は `clamp(118px, 38vw, 160px)`。375px では 142px、390px で 148px、430px 以上は 160px で固定。アスペクト比は原画のまま（`height: auto`）。
- 820 / 1180px（iPad）では患者レイアウトの最大幅（約 448px）内で 160px。余白が広がるだけで配置は同じ。
- ログアウトは利用頻度が低いので最下部の控えめなリンクに移動。ファーストビューは「挨拶 → 挿絵 → 主役カード」だけになる。
