# Phase E — 「パッと見てわかる」ための患者・医療者画面の再構成（2026-11-03）

きっかけ: 実機確認での評価 40/100。患者は「処方されていない教材も含めた一覧がない」「今回の処方・未学習がパッと見てわからない」、医療者は「患者がどの領域をどれくらい理解しているかがパッと見てわからない」。

確定した方針（ユーザー判断）:
- 処方されていない教材も **自由に学習できる**（処方分と自主学習は区別して記録し、医療者にも表示）
- 理解度は **3 段階（確認できた／もう一度／未学習）**。点数は詳細に回す
- Phase E を実施してからデモ素材づくりに進む

画像: `compare/before_after_*.png`、`app/`（390 標準・文字拡大、医療者 1180・820・絞り込み）、`before/`。

## 2. 医療者側（診察画面）

- 見出しの下に **要約帯**: 前回の処方の完了数、もう一度の領域（名前つき）、未確認の質問、自分で学んだ教材。
- **1 全体を見る — 理解の地図**: 6 領域 × 3 段階。各セルに完了数と教材名（「処」= 処方、「自」= 自主学習）。押すと「前回の学びから」をその領域に絞り込み（「『薬物療法』に絞り込み中 ／ すべて表示」）。処方も学習もない領域は押せない。
- **2 確認・説明する — 前回の学びから**（Phase D の質問行など）、**3 次の処方 — 次の情報処方**。
- 1180 は 6 列、820 は 3 列 × 2 段、390 は 2 列。要約帯は 1180 で 4 列、それ以下は 2 列。

## 3. サーバー側の変更（ロジック）

| 項目 | 内容 |
|---|---|
| 学習できる教材 | 処方された版（旧版を含む）に加えて、**現在公開中の版**で、共通教材または患者に処方したことのある病院の独自教材。下書き・承認待ち・取り下げ・処方されていない旧版、他院の独自教材は 403（`NOT_AVAILABLE`）。進捗・確認問題・質問は同じ入口で判定 |
| 理解の集計 | 処方された教材＋自主学習した教材（進捗または挑戦があるもの）。採点ルール（最新の完了挑戦、旧版・安全上の無効化の扱い）は不変 |
| 宿題スナップショット | 処方セット単位のまま（自主学習は含めない）。不変 |
| 新規 | `getPatientLibrary`（一覧と状態）、診察サマリーに `learning`（処方・自主学習した教材の状態と 3 段階） |
| 未変更 | QR 共有、60 分セッション、処方、採点、質問の明示保存、教材の生成・承認・公開、非公開画像の配信 |
