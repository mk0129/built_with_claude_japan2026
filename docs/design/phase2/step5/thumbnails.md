# 教材カードのサムネイル一覧（画像の制作は別作業）

- 置き場所: `public/thumbnails/<ファイル名>`。登録: `src/concept-d/thumbnails.ts` の `THUMBNAILS` に「教材名: { file, alt }」を追加すると、患者の教材カード・教材詳細と、医療者の教材ライブラリのカードに表示される（Figma のレイアウトのまま。患者の教材カードは枠いっぱい（cover）、患者の教材詳細と医療者の教材ライブラリのカードは画像全体を枠内に表示（contain。2026-11-04 変更: 横長の枠で頭部・手元が切れていたため）。教材詳細のサムネイルの下には「監修済み画像」の説明を出さない）。未登録の教材は Figma の「画像準備中」の枠のまま。
- 教材 ID はデータベースごとに異なるため、キーはシードの教材名。
- **サムネイルは雰囲気を伝える一般的なイラスト**（成人患者向けの水彩調、人物・生活場面）。臓器・病変・手技・薬など**医学的な内容を描かない**。
- **医学的な解説図**（体の仕組み・病期・手術の方法など）はサムネイルとは別で、既存の図解アセット（`figure_assets` / `figure_placements`）として登録し、医療者の内容確認（承認）後にだけ学習画面に表示する（未承認は URL も配信しない）。

## 必要なサイズ（表示枠の実測。2 倍解像度で用意）
| 表示枠 | 表示サイズ（CSS px） | 推奨書き出し |
|---|---|---|
| 患者の教材カード（スマホ・タブレット共通） | 88 × 72（11:9） | 中央に主題 |
| 患者の教材詳細（スマホ 390px） | 350 × 262（4:3） | — |
| 患者の教材詳細（タブレット 768px） | 696 × 390（約 16:9） | — |
| 医療者の教材ライブラリのカード（1180px） | 300 × 88（約 3.4:1） | — |
- 1 枚の原画で全枠に使う場合: **1600 × 1200（4:3）の WebP**。主題（人物の顔・手元）を中央の 1600 × 470 の帯に収める（16:9・3.4:1・11:9 の切り抜きで欠けないように）。文字は入れない。
