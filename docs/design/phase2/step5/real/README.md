- 画面2「どんな薬があるか」: 薬には飲み薬と注射があり、組み合わせは担当医が決めます。 — 抗エストロゲン薬（タモキシフェンなど）は、がん細胞がエストロゲンを受け取るのを妨げる飲み薬です。アロマターゼ阻害薬は、閉経後の体でエストロゲンが作られるのを抑える飲み薬です。LH-RHアゴニストは、閉経前の方の卵巣の働きを一時的に抑える注射です。
- 画面3「治療を続ける期間」: 治療期間は人によって違い、担当医と相談して決めます。 — 手術のあとのホルモン療法は、5年間続けることが基本です。再発のリスクなどに応じて、10年まで延長することもあります。
- 画面4「薬をやめたくなったとき」: 自分の判断で薬をやめたり、量を減らしたりしないでください。 — やめたいと感じたときは、その理由を担当医や薬剤師に伝えてください。飲み忘れたときは、2回分をまとめて飲まず、迷うときは薬剤師に確認します。他の病院で薬をもらうときや、市販薬・サプリメントを使いたいときは、事前に担当医か薬剤師に相談します。
