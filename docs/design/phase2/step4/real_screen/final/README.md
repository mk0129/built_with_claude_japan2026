## 結果: **Claude は要約を生成したが、安全上の記述を含む項目があったため要約全体を表示せず、ルールベースに切り替えた**
- 呼び出し: 1 回（`[claude] call 1/1`）。モデル `claude-sonnet-5-5`、入力 8,390 / 出力 3,170 トークン（費用の目安 約 $0.07。Sonnet 級の単価を仮定）。
- サーバーの検証: 18 項目中 16 項目が通過、2 項目が不採用 —「禁止された記述：正常・異常の判定」1 件（安全上の違反）、「件数が根拠と一致しない」1 件。安全上の違反が 1 件でもあれば要約全体を表示しない設計のため、`status: fallback`。
- 不採用になった文の本文は、検証できない記述を残さない設計のため記録していない（理由の種類だけ）。1 回目の検証（インメモリ DB）でも同じ種類（正常・異常の判定）で不採用になっており、モデルがバイタルの値に「高め」「正常範囲」などの評価を添える傾向がある可能性が高い。今後のため、理由に一致した禁止語（こちらの一覧の語）を含めるよう修正した（追加の呼び出しなし）。禁止語の条件は緩めていない。
- 画面: 見出し「構造化サマリー（記録から自動整理・ルールベース）」と「AI要約は表示していません：AI 要約に安全上の記述（解釈・診断・因果・Grade など）が含まれたため表示しません」で区別（`01_summary_top`・`02_ai_summary`）。各文から根拠の記録を表示（`03〜05_sources_*`・`sources_clicked.json`）。
