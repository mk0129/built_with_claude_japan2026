## 2. 主要 5 画面の Before / After

### 2.1 患者ホーム（`shots/before_home_*.png` → `shots/after_home_*.png`）
- 維持: 主役カード 1 枚＋大きな 1 ボタン、進捗バー、一覧は行、共有の案内は末尾 1 行。
- 変更: 挿絵を 150px→118px（compact）にして氏名を 1 行に。「次に読むもの」を terra の eyebrow に、読み終えた数を terra のピルに。一覧の右端に状態文字（読み終えた／未着手）を追加し、リングは主色。下部タブを線画アイコンに。
- 根拠: 監査で「次の行動が分かる」は ◎ のため構成は変えず、見出し階層と状態の読み取りだけを強める。
- 文字拡大: `after_home_390_large.png`。氏名は 1 行、主ボタンは画面内。

### 2.3 クイズ結果（`shots/before_result_*.png` → `shots/after_result_*.png`、テーマ選択後 `after_result_{390,430}_picked.png`）
課題「質問候補が長く、最初の画面が文章で埋まる」への案: **2 段階**。
1. 段階 1: 短い質問テーマをチップで選ぶ（関連画面のタイトル＋「もう一度／わからない」の種別。文章は出さない）。
2. 段階 2: 選んだテーマごとに短い定型文（1〜2 行）が編集欄に入り、文字数を表示。4 択と「次の診察に残す」はその下。
- Before（390）は候補 2 件の文章（各 4〜5 行）で初期表示の半分以上を占めた。After は見出し＋タイル＋テーマチップ 2 つ＋4 択が初期表示に入り、文章は選んだ後にだけ現れる。
- 維持: 自動送信なし、明示ボタンのみ、「すぐの返信はありません。緊急のときは病院の連絡先へ」、採点・履歴のロジック。
- タイルは数字を状態色の文字にし、ラベルに小さな線画アイコン（✓ ！ ？）。点数は折りたたみのまま。

### 2.4 医療者の診察・理解確認（`shots/before_consult_*.png` → `shots/after_consult_*.png`）
- 維持: 「今日の確認事項」が主役、質問 → 誤答・わからない → 未完了の順、各行に主アクション 1 つ、残り時間・延長・終了が上部に常時。点数より質問・誤答・未完了が目立つ構成。
- 変更: 群ごとに番号付きの行、群見出しに線画アイコン。誤答の行で「患者の答え → 正解」を 1 行に、正解を太字。理解確認スコアは右列の末尾で折りたたみ（参考値）。処方パネルは lg 以上で右列に常設し、候補と「n 件を処方する」を上、テンプレート／検索を下に。
- 緊急と未確認の区別: 未確認の質問はテラコッタの枠＋「未確認」タグ（状態。緊急ではない旨を添える）。回答に危険な行動（例: 眠れない・食欲がない状態が続くとき →「治療をやめる」）が含まれる誤答は赤の枠＋「緊急の確認」タグ＋警告アイコンで、群の先頭に置く。見出し横の集計も「未確認の質問 1 ／ 緊急 1 ／ 誤答・わからない 3 ／ 未完了 1」と分ける。
- 文字サイズ: 質問文・誤答の行・確認事項の見出し・教材名は 16〜16.5px、日付や付帯情報は 15px、ピルは 12.8px。
- 390: 行内のボタンは幅いっぱいで折り返し（`after_consult_390.png`）。横スクロール 0、44px 未満の操作要素 0。

### 2.5 教材スタジオ: 構成案の選択（`shots/before_outline_*.png`（擬似生成 1 案）／ 3 案の内容は `../../screenshots/day6_20261103/real/d5_02_b_outlines.png` → `shots/after_outline_*.png`）
- 変更: 構成案を画面の主役に。原資料は 1 行の要約＋折りたたみ、「構成案を作る／テーマを指定」の 2 カードは見出し横の 2 リンクに縮小、案カードは「タイトル → 画面構成（番号付き）→ 学習目標 → 対象・領域 → 根拠（折りたたみ）→ ボタン」の順。枠線・バッジ・説明文を減らし、ステッパーは 1 行。
- 維持: 同じ項目を同じ順に並べる比較、「おすすめ」なし、ボタンは 1 枚に 1 つ、必須事項の候補数を見出し下に表示。
- 820 は 3 列のまま、390/430 は 1 列（`after_outline_390.png`）。

## 3. 改善の根拠（まとめ）
- 主色を落ち着いた青（#365C79）に寄せ、状態色（理解できた＝緑、ちがう答え＝テラコッタ、わからない＝砂）を少量の面として残すことで、現行 C2 の「静かさ」を保ちながら主要ボタン・リンク・進捗の識別性を上げる（白文字コントラスト 5.5:1 → 7.6:1）。
- 見出しの階層を eyebrow（小・terra）→ 見出し → 補助の 3 段に統一し、画面間で読み方を揃える。
- 患者画面の余白・角丸・タップ領域は維持（高齢患者配慮）。医療者画面だけ密度を上げる。
