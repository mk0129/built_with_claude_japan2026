# shiori 視覚デザイン引き継ぎパッケージ v1.0

**用途：** C（静かなウェルネス）を基本とする画面改善と、医学的意味のある外部制作イラストの導入を分業するための指示書。

## 入っているもの
- `CLAUDE_CODE_INSTRUCTIONS.md` — Claude Codeへ渡す設計・実装指示（今回は承認前モック制作）
- `VISUAL_ASSET_SPECS_5.md` — ChatGPT画像制作のための優先5アセットの学習目標・画風・医学的注意・制作プロンプト
- `ASSET_MANIFEST.csv` — ID、ファイル名、利用画面、alt text、監修状態
- `ASSET_QA_AND_IMPORT.md` — 納品・安全・取り込みのチェックリスト

## 作業分担
**Claude Code：** Cの改良モック3画面、教材画面別アセット要求表、図解の枠・ラベル／矢印・監修フロー・アクセシビリティの設計。医学的な最終図を丸・四角の寄せ集めで代作しない。

**ChatGPT画像生成：** 医学的監修を前提とする解剖・相談・治療の具体的なイラストと、ホーム用の情緒絵を**独立ファイルとして1点ずつ**制作。画像制作後に実画面にはめて評価し、医学的図は公開前承認を取得。

## 状態
**このパッケージは制作仕様と指示です。画像5点の完成データはまだ含んでいません。**

## 最初の操作
1. この4ファイルをリポジトリの `docs/design/` などに配置。
2. Claude Codeへ `CLAUDE_CODE_INSTRUCTIONS.md` を読み、`VISUAL_ASSET_SPECS_5.md` に従ってPhase Aを行うよう指示する。
3. C改良版3画面ができたら、ChatGPTで優先1〜2点の絵柄を確認してから5点を制作する。
4. 医療者レビューで承認できた図のみ本番教材へ配信する。
