# Claude Codeへの指示：CベースUI＋医学的に意味のある図解（承認前フェーズ）

## この依頼の目的
患者向けのデザインは **C：静かなウェルネス** をベースにする。B案から採用するのは「1画面1学習目標」「進捗・CTAの明快さ」などの**学習構造**だけであり、現行Bの幾何学的な図解・色面の羅列は採用しない。

現在の医学的図解（丸、四角、＋、矢印、帯を並べただけの図）は、デザイン面だけでなく内容理解にも不十分。医学的な図は**抽象図形の自動生成を禁止**し、具体的な解剖・治療行為・相談場面に基づく図解を、独立したアセットとして作成する。

添付の `VISUAL_ASSET_SPECS_5.md` と `ASSET_MANIFEST.csv` を読み、次の2段階で進める。

## Phase A：仕様・モックの更新のみ（本体UIの大幅変更はしない）
1. `docs/design/concepts/c_wellness_home.png`、`c_wellness_learn.png`、`c_wellness_result.png` を基準とし、患者ホーム・「病期とは」の教材1画面・クイズ結果画面の**C改良版モック3画面**を作成する。患者向けは390px幅と430px幅で確認可能なものにする。
2. C案の低彩度・穏やかな余白・落ち着いた文字の印象を維持する。B案から取り入れるのは明確な進捗、1画面1命題、読みやすいCTAと理解を助ける図の情報構造だけ。ブランド色・フォントはまだ最終固定しない。
3. 外部の医学的図解アセットが未完成の箇所は、**意味のある代替テキストと図解専用プレースホルダー**を表示する。「丸3個・矢印だけ」で医学的内容が伝わるように見せかけない。
4. 画像アセットは今後ChatGPTで**1点ずつ制作・医学的監修**したのち取り込む。Claude Codeに汎用図形で最終画像を代作させない。新しい画像が入った時に差し替えやすいコンポーネントと設計にする。
5. 8〜10教材 × 各3〜5画面を走査し、**各画面の学習目標・必要な図解の有無・図解の具体的な意味・素材ID・監修ステータス**を一覧にした `docs/design/MEDICAL_VISUAL_REQUIREMENTS.csv` を作成する。元資料にない医学的知識を創作せず、不明点は `要医療者確認` とする。
6. 下記の画像統合仕様を定義し、3画面のモックで検証する。認証・採点・QR・教材バージョン・処方ロジックは一切変更しない。
7. 作成した3画面のスクリーンショットと、Cの元案からの改善点、リスク、情報量・可読性の自己評価を提出する。**ユーザー承認があるまで全画面への適用をしない。**

## 画像をUIに組み込む実装要件
- 図解の画像本体は `public/assets/medical/`、情緒的イラストは `public/assets/editorial/` を候補とする。ただし利用許諾・公開可否が確定したファイルだけを配置する。元資料・未許諾素材を公開リポジトリへ入れない。
- 画像の説明と学習目標は文字で持ち、画像に埋め込まない。必要なラベル・矢印・注釈・凡例はHTML/SVG上の**別レイヤー**とし、スマホでも可読・拡大可能にする。
- 医学的な図解のメタデータとして `asset_id`, `material_id`, `slide_id`, `learning_objective`, `source_refs`, `review_status`, `reviewer`, `reviewed_at`, `version`, `alt_text`, `copyright_status` を管理可能にする（既存スキーマ・実装方針に整合させ、必要な変更は事前提示）。
- `review_status != approved` の医学的図解は患者向け本番教材に**表示しない**。管理者プレビューでは「監修待ち」を明確に表示する。未承認図解なしでも学習できる、監修済みテキストへのフォールバックを確保する。
- 図解を単なる装飾として縮小しない。教材のファーストビューで要点が理解できる大きさにし、図の意味を短文で補足する。患者の文字拡大・音声読み上げ・VoiceOver、375/390/430pxにも対応する。
- 患者向けイラストは**C案の温かく静かな世界観**に統一。ただし理解を損なうほど淡い線や低コントラストにしない。医療者画面には装飾的な水彩を無理に持ち込まない。
- 必須ではない装飾は背景的に扱い、情報を妨げない。図解は代替テキストだけでなく、必要に応じて長い文章による内容説明を付す。

## 非交渉事項
- 医療内容を勝手に補完・簡略化・診断しない。乳がん病期の図で、T/N/Mの3要素だけから全患者の病期が一意に決まると断定しない。乳がんの病期評価には採用する分類体系に応じて生物学的因子等が関係することがある。どの基準を扱うか監修者に確認する。
- 副作用の図を患者個人への緊急度判定・医療指示と誤認させない。具体的な連絡基準は施設の監修済み資料のみ使用する。
- ラベルが必要な医学図を画像生成AIの描いた文字に依存させない。アセット自体には原則文字・矢印・番号を入れず、意味を担うラベルはコード側で管理する。
- 画像生成AIの出力を医学的に正確だと自動認定しない。学習目標、原資料、レビュー、版管理を必須にする。
