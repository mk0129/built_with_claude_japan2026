## 監修優先事項（重要）

1. **MED-001-02 N：** 緑色のリンパ節・リンパ路が頸部の高い位置まで伸びるように見える。乳がん領域リンパ節の適切な解剖（腋窩、鎖骨上・下、内胸など）に沿うか、特に優先確認する。正確でなければ画像差し替え・描き直し。現在の画像をそのまま医学的承認しない。
2. **MED-001-03 M：** 肺・肝・骨は遠隔転移部位の例。骨盤と近位大腿骨・病変位置が解剖学的に妥当か、臓器位置に誤解がないか監修。複数部位への転移が必須と誤認されない説明を添える。
3. **MED-001-01 T：** 乳房内の病変概念として簡略化されている。T分類の定義（主に原発腫瘍の大きさ・局所進展など）をこの絵だけで正確に説明できるとは限らない。本文・注記と対応させる。
4. 予後病期分類における腫瘍の生物学的特徴等の扱いは、採用分類を明示した教材本文で説明する。
