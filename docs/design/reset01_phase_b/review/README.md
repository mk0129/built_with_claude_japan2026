# Phase B レビュー用の確認結果（2026-11-03、UI 変更なし）

## 1. 結果画面「質問の箱」: 参照 194px → 実装 365px の内訳（390、padding 18px×2 = 36px を含む）

| 行 | 参照 | 実装 | 差の理由 |
|---|---|---|---|
| eyebrow「次の診察につながる」 | 16 + 余白 10 | 23 + 10 | 文字 12→13px |
| 見出し（2 行） | 51 + 6 | 51 + 6 | 同じ |
| 説明文 | 20（1 行、12px）+ 13 | 46（2 行、14px）+ 13 | 可読性基準で 14px にしたため 2 行に |
| テーマのチップ | 38（1 行） | 98（2 行） | テーマ名が教材の画面タイトル（「病期は治療の目安」「検査結果の見方」）で長く、3 つ目「自分で書く」が 2 行目へ。文字 12→14px |
| 明示保存の注記 | なし | 69（3 行） | 参照に無い追加。「保存は『次の診察に残す』を押したときだけ…緊急のときは病院の連絡先へ」 |
| 合計 | 194 | 365 | +171 |

短くする案（判断待ち。2 段階構成は維持）:
- A. 注記を 1 行に短縮して保存ボタンの直下に移す（例「保存はボタンを押したときだけ」）: −46〜−69px
- B. チップを 13px・余白 9px 11px（参照値）にする: 2 行目が解消すれば −60px
- C. 説明文を 13px にして 1 行に: −26px
- A＋B で約 236〜260px（参照 +40〜65px、文字は可読性基準を維持）。

## 2. 図解の番号 ①②③（`learn_fig_lymph_390_2x.png`）
- 番号は図の中の「位置」と凡例を結ぶための印で、順序の意味は持たせていない。ただし「3 つの図は病気がこの順番に進むという意味ではありません」と図の下で注意している横で、図の中に 1・2・3 が並ぶため、**進行順と誤読される余地はある**（リンパ節タブでは 1 乳房内の病変 → 2 わきの下 → 3 鎖骨 と、実際の広がりの順に見える配置）。
- 代案（判断待ち）: (a) 番号をやめて色＋形の印（● ■ ▲）にし、凡例も同じ印で対応させる。(b) 番号は残し、凡例の先頭に「番号は場所の目印で、順番ではありません」を 1 行添える。(c) 参照どおり図の上の印をなくし、凡例だけにする（位置の情報は失われる）。
- 推奨: (a)。順序を連想させず、位置の対応は保てる。

## 3. 下部タブの 11px（`home_tabs_390_2x.png`）
- 実測: 11px / 650 / 主色（選択中）・灰（非選択）。参照は 10px。アイコン 21px と組み合わせて識別はできるが、通常表示で高齢の患者が読む文字としては小さい（本文 16px の 69%）。
- 推奨: 12px（拡大時 13px は現状どおり）。タブの高さ 76px は変えずに収まる。
- 図のタブ（乳房／リンパ節／ほかの臓器）は 14px / 750 / 高さ 44px で、通常表示でも読みやすい（`learn_segments_390_2x.png`）。
