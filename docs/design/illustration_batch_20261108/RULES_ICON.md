# マスター・デザインルール：アイコン（教材サムネイル・セットのカバー）

対象: 教材カード・教材一覧・医療者の教材ライブラリに出る**教材サムネイル**（横 4:3）と、患者ホームのセットカード・テーマカードに出る**カバー**（縦 4:5）。既存の正式画像（Codex 制作・2026-11-06）と同じ画風にそろえる。

## 1. 画風
- **単色の連続線画**。線色は #315E68（ダークティール）1 色、細く均一な線、塗り・陰影・グラデーションなし。
- 背景は透明（納品は白背景でも可。取り込み時に白を透明にし、描かれた画素の 95% 以上が #315E68 に近いことを検証する）。
- 余白を広く取り、主題は 1 つ。題材は**雰囲気を伝える生活の物・場面**（手帳・カップ・椅子・帽子・靴など）。
- **医学的な内容を描かない**（臓器・病変・手技・薬・注射器・装置）。体の仕組みの図は別の仕組み（医学的図解）で扱う。
- 文字・数字・矢印・ロゴ・枠線を描かない。

## 2. サイズと構図
| 種類 | 原画 | 配信 | 構図 |
| --- | --- | --- | --- |
| 教材サムネイル | 1600×1200（4:3） | WebP 1600×1200 ＋ 192×144 PNG（カード用の縮小） | 主題を**中央の横長の帯 1600×470** に収める（教材詳細では 16:9・医療者の一覧では約 3.4:1・カードでは 11:9 に切り抜かれる） |
| セット／テーマのカバー | 800×1000 または 1600×2000（4:5） | WebP 800×1000 | 主題を上 2/3 に置く（カードの下部に文字が重なる） |

- 線の太さは 1600px 幅で 6〜10px 相当（縮小して 48px のカードでも線が消えない太さ）。
- 細かい模様・小さな部品は縮小で潰れるので避ける。主題は 2〜3 個の物まで。

## 3. 納品形式
- 1 点 1 ファイル、PNG（透過が望ましい。白背景でも可）。ファイル名は一覧の `id`（例 `THUMB-neuropathy.png`、`COVER-prehab_set.png`）。
- 取り込み: `npx tsx scripts/assets/import-illustrations.mts <フォルダ>` が WebP と縮小 PNG を書き出し、`src/concept-d/thumbnails.ts` に追記する行を出力する。検証: `node scripts/assets/validate-images.mjs`。

## 4. 受け入れ基準
- [ ] 1 色の線画で、塗り・影がない。
- [ ] 透明背景（透明な画素 50% 以上）、白いハローがない。
- [ ] 主題が中央の帯（サムネイル）／上 2/3（カバー）に収まる。
- [ ] 医学的な物・文字・ロゴがない。
- [ ] 48px に縮小しても何の絵か分かる。

## 5. 登録先（キーは教材名・セット名と完全一致）
- 教材サムネイル: `THUMBNAILS["<教材名>"] = { file, alt }`（alt は「〜の線画」）。
- セットのカバー: `SET_COVERS["<患者向けのセット名>"]`（テンプレート名と同じ。例外: 「初回診断時セット」→「診断時セット」）。
- テーマ: `THEME_IMAGES["医療費シミュレーター"]` など。
