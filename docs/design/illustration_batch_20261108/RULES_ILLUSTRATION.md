# マスター・デザインルール：挿絵（イラスト）

対象: 患者の学習画面（1 画面 1 主題）の画像枠に入る**場面のイラスト**（editorial）。医学的な解説図（体の仕組み・病期・手技）は対象外で、別の監修フロー（`figure_assets` の medical）で扱う。

## 1. 画風（既存の MED-001・EDI-001 と同じ系統）
- 大人向けの日本のウェルネスサービスに合う、**静かで上質なエディトリアル・イラストレーション**。
- 主線は細めの落ち着いたダークティール（#315E68 付近）。繊細だが消えない線。
- 色は淡いセージグリーン・温かいサンド・くすんだローズ・ブルーグレーの控えめな水彩。塗りは透明感のある薄塗り、濃い彩度は使わない。
- 余白を多く取る。背景は**白（最終的には透明）**。四角い背景カード、白ベタの枠、枠線、ドロップシャドウ、グラデーション、3D、幼児向けキャラクター、素材シート化はしない。
- 人物は成人の日本人として自然な比率。表情は穏やかで、作り笑いや闘病を強調する記号（点滴・包帯・涙）は描かない。性別・年齢は教材の主題に合わせて偏らせない（乳がん以外の教材では男性・高齢者も）。
- **画像内に文字・数字・矢印・ラベル・ロゴ・ブランド名を描かない。** 文言はすべて UI 側で重ねる。

## 2. 描いてよいもの・描かないもの
- 描いてよい: 自宅・外来の待合・診察室の机など生活と医療の**場面**、お茶・手帳・体温計・スマートフォン・帽子・手袋などの身近な物、同じ目の高さで話す医療者。
- 描かない: 解剖・腫瘍・手術の場面・針・血液・薬の粒のクローズアップ・装置の操作・実在の病院や製品に見える意匠・病院名やロゴ・子どもの泣き顔。
- 医療者は無地の白衣や制服で、器具を手に持たない。
- 「吐き気」「脱毛」などの主題でも、つらさを強調せず**対処している場面**（少量ずつ食べる、帽子を整える）を描く。

## 3. 構図とサイズ
- 原画: 4:3 横（推奨 1536×1152）。表示は患者画面 350×262（スマホ）／696×390（タブレット、16:9 に切り抜かれる）。
- 主題は中央の横長の帯（高さの中央 60%）に収め、上下を切っても意味が欠けないようにする。
- 1 枚に 1 場面。複数の小場面を 1 枚に並べない（分割が必要なら別アセット）。

## 4. 納品形式
- 1 点 1 ファイル、PNG。背景は白のままで可（取り込み時に `scripts/assets/import-illustrations.mts` が白を透明に落とす）。透過 PNG で納品できればそれが望ましい（白いハロー・四隅の地色なし）。
- ファイル名は一覧の `id`（例 `EDI-SE-02.png`）。配信名は取り込み時に付け替える。
- 容量は 1 枚 1.5MB 以内を目安。

## 5. 受け入れ基準（取り込み前に目で確認）
- [ ] 文字・数字・矢印・ロゴが入っていない。
- [ ] 解剖・手技・器具のクローズアップがない。実在の施設・製品に似ていない。
- [ ] 線の色・太さ、色数・彩度が既存の挿絵（`public/assets/medical/`、`public/assets/editorial/EDI-001.png`）と並べて違和感がない。
- [ ] 主題が中央の帯に収まり、16:9 の切り抜きで欠けない。
- [ ] 白を透明にしたときに縁が汚れない（細い白い輪郭が残らない）。

## 6. 登録と表示
- `src/server/db/seed-figures.ts` に `type: "editorial"`・`placements: [{ materialTitle, slideSeq }]`・`delivered` で登録する（editorial は医学的監修の対象外として承認扱いで表示される。medical は監修プレビューからの承認が必要）。
- 公開デモは `.judge-demo/app/fixtures/patient-figures.json`（教材名 → スライド番号 → 画像）に追記する。
- 画面側の alt は「〜のイラスト」。caption は付けない（場面の挿絵であり、説明図ではない）。
