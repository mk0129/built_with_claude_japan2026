## 所見と推奨

- **第一候補 B は妥当**。ただし「要点＋図」を最初の画面に収める案であり、本文は 1 スクロール弱必要になる点は A と同じ。C2 の「1 画面 1 要点」を保ち、要点を読んでから図を見る順序は患者さんの理解の流れに合う。
- **C は「本文が最初に読める」唯一の案**だが、図解が画面外に落ちるため、図解を作った意図（病期の 3 つの情報を視覚で押さえる）が弱くなる。文字拡大時はさらに顕著。
- A は図が主役になるが、要点が図の下に来るため「何の図か」が先にわからない。
- B の弱点（本文が画面外）は、図の高さで決まる。改善余地: (1) 図のアスペクトを 1:1 から 4:3 相当に切り出す（図解の作り直しが必要・今回は不可）、(2) 「短い本文」の 1 文目だけを図の上に置く（B と C の折衷。要点 → 1 文 → 図 → 続き）。(2) は MED-001 の本文が 2 文なので効果が大きい。採用するなら B を基本に、本文 1 文目の位置を実機で確認したい。
- 医学監修の注記・出典は「図について（監修・出典）」に集約した 1 行を 3 案とも残した。開いた状態の確認は `learn_B_390_full.png`。

## 判断をお願いしたい点
1. B を採用するか（折衷案 (2) を含めるか）。
2. 読み上げボタンの小型化（72px → 52px）で問題ないか。高齢患者の押しやすさを優先するなら 60px に戻す。
3. 図の注記を「図について」に畳んでよいか（監修注記を常時表示にする方針なら、1 行の短文表示に変更する）。
