## 付随して修正した不具合

- クイズ開始 API が同時に 2 回呼ばれると進行中の挑戦が 2 件作られ、再開時に回答が消えたように見える（開発モードの二重初期化で再現。本番でも二重タップで起こり得る）。`quiz_attempts` に「進行中は患者×版で 1 件」の部分一意インデックスを追加し、衝突時は既存の挑戦を返すよう修正。統合テストを追加。Supabase にも適用済み（マイグレーション 0003）。
- 医療者ダッシュボードの「前回の宿題」は、この診察で確定した分がない場合に当院の最後に確定したスナップショットを表示する（表示だけのフォールバック。確定は従来どおり処方元病院の次回診察で一度だけ、値は不変）。

## 修正後の操作フロー

**患者**: ログイン → ホーム最上部「次に読む教材」→「読む・聞く」→ 説明（目次・読み上げ・文字拡大、下部タブなし）→「確認問題へ」→ 1 問ずつ回答と解説 →「結果を見る」→ もう一度見ておきたいところ／できたこと／次にできること → 先生に伝える → ホーム。中断時はホームが「続きから読む」「確認問題の続きから」を最上部に表示。

**医療者**: QR / 6 桁コード → 承認 → 「今日の確認事項」で未確認の質問・誤答・未完了を確認 →「対応を記録」で確認済み／対応済み（方法・メモ）→「再処方」「関連教材を処方」で候補へ →「処方を確定する」。
