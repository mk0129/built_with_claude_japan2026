- **診断時セットの判定**: 処方の記録にテンプレートの ID がないため、教材の一致で判定している。医療者が 3 教材を個別に選んでも「診断時セット」と表示される。正式にするには処方の記録にテンプレートを残す変更（処方の処理・DB の変更）が必要で、今回は行っていない。
- **教材の内容（修正提案）**: 「サブタイプと治療方針のつながり」の「HER2 が陰性の場合はこの薬は使いません」は、HER2 低発現の転移・再発乳がんで使われる薬があるため、言い切りを避けた表現への見直しを提案（例: 「HER2 を狙う薬が使えるかどうかは、HER2 の検査結果をもとに担当医が判断します」）。医学的な監修のうえで判断してください。トリプルネガティブの説明もない。

- **医療者の残り時間**: ヘッダーは分単位（切り上げ）、左の欄は分:秒。
- **ログイン画面**: デモ用アカウントの一覧に「教材承認者・管理者」の説明が出る（アカウントの役割の説明として残した）。
