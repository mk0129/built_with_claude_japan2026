- 要約の全項目・ルールベースへの切り替え・再生成は「要約の全項目」を開いたときだけ（従来どおり）。カード・統合タイムライン・在宅経過表への導線・共有終了は変更なし。

## 2. Claude への指示（生成する本文だけ）
- SYSTEM: 診察前に医師が読む日本語で 1 項目 1 つの確認事項（1 文・60 字程度）。AI・検証の紹介文を書かない。症状は症状名・日付・患者評価、長い列挙は代表値と直近の記録（日付付き）、直近に記録がない期間を推定しない、異なる症状・別時刻・持続や欠測は一律に削らない、節の重複を避ける。質問は自由記述なら原文全体を「」、選択のみなら「選択した回答：<ラベル>」（「」にしない）。「わからない」を能力の評価にしない。数値・単位・日付・引用は sourceIds で照合できるものだけ。診断・重症度・因果・治療提案を書かない。合計 16 項目以内。
- buildUser: 質問に `input`（free_text / selection）と、選択のみは `selectedLabel`（自由記述は原文 `text`）。
- 照合（`validateItems`）: 質問の節は根拠 ID ごとに、自由記述は原文の完全一致の引用、選択のみはその記録の選択コードに対応するラベル（「選択した回答：…」、原文の引用の形は不可）。スキーマ・ほかの照合・部分除外・代替表示・データのハッシュは変更なし。
- 変更していない: ルールベースの要約（`intervisit-rules.ts`）。選択のみの回答を「」で引用するため、開発用の擬似生成（ルールベースの文を使う）では該当の 1 項目が新しい照合で除外される（E2E で「照合できなかった1項目を除外」と表示されることを確認）。
