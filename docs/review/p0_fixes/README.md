## 直していないもの

- 体調記録の日時の英語表記（11/06/2026, 01:20 AM）: アプリの文言ではなく、ブラウザ標準の日時入力（`datetime-local`）の書式。書式はブラウザ自体の表示言語で決まり、レビュー用のヘッドレス Chromium は英語で描いていた（ページの言語設定 ja-JP では変わらない）。日本語設定のブラウザ・端末では日本語の書式になる見込みのため、撮影前に実機で確認する。表示を自前の書式に置き換える変更は、入力の操作性に影響するため今回は見送った。
- 患者の共有中の残り時間が開始直後に「61分」と出る（医療者は「60分」）。切り上げの表示の差で、今回の範囲外。
