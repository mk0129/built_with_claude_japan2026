# 医療者側 UI の点検（2026-11-08・患者側と同じ観点）

観点は患者側と同じ: 目的までの手数、囲いの入れ子、説明文の量、配置の不具合（はみ出し・重なり・小さいボタン・見切れ）、色の使い方。対象は審査用デモ（架空患者と接続した状態）の 4 画面を 1180×820（PC）と 820×1180（タブレット縦）で確認。機械的な点検は `scripts/review/clinician-layout-audit.mjs`、結果は `clinician_layout_audit.md`。

## アクセス制御に関する補足

質問の「解決」は、既存の `requireActiveConsultation`（患者の承認・60 分・未終了・担当の医療者）をそのまま通したうえで、その患者の質問だけを更新する追加のエンドポイント。認証・QR 連携・60 分の判定そのものは変えていない。統合テストで、他院の医療者 403・他患者の質問 404・終了後 403・原文不変を確認。

## 変えていないこと

- 医療者側の CTCAE の凡例と「正式な Grade 判定ではない」注意は残した（患者側では削除）。
- 診察サマリーは情報量が多い画面で、質問の原文・理解確認の設問・推薦理由など「説明文」として数えられる文字が 1,100 字前後ある。これは患者の記録そのものなので削らず、折りたたみ（AI 外来間サマリー）と省略表示（推薦理由）で初期表示を抑えている。
- 色: 医療者側は既存の落ち着いた配色（青緑の単色＋状態色）のままで、領域色は教材ライブラリのチップと処方状況のバッジだけに使っている。

## 点検の結果（最終）

`clinician_layout_audit.md` を参照。1180×820・820×1180 の 4 画面 × 6 状態で、はみ出し・重なり・小さいボタン・見切れは 0。囲いの入れ子は在宅経過・教材ライブラリで 2、診察サマリー（質問の番号の丸印）と教材スタジオ（図解エディタ）で 3。
