# 医療者側 UI の点検（2026-11-08・患者側と同じ観点）

観点は患者側と同じ: 目的までの手数、囲いの入れ子、説明文の量、配置の不具合（はみ出し・重なり・小さいボタン・見切れ）、色の使い方。対象は審査用デモ（架空患者と接続した状態）の 4 画面を 1180×820（PC）と 820×1180（タブレット縦）で確認。機械的な点検は `scripts/review/clinician-layout-audit.mjs`、結果は `clinician_layout_audit.md`。

## 見つかった問題と対応

| 画面 | 問題 | 対応 |
| --- | --- | --- |
| 診察サマリー | 見出しの上に「診察」の小見出し、S・O 欄に「S・O 患者の今の状況」「在宅での体調（患者本人の記録）」「患者評価 0〜4（CTCAE Grade ではありません）」と見出しが 3 段 | 小見出しを削り、「在宅での体調」1 行に。S は「0〜4・本人の評価」、O は「期間内 N 日・M 件」だけ |
| 診察サマリー | バイタルが「収縮期血圧」「拡張期血圧」の 2 枠 | 「血圧 124/77」の 1 枠に（色の目安は上下の強い方） |
| 診察サマリー | バイタル下の目安の注記が 3 行 | 1 行に短縮（全文は title 属性で） |
| 診察サマリー | 「期間を変更」の高さ 17px、AI 要約内の「ほか N 件」「作成情報」などが 22px | すべて 32px 以上に |
| 診察サマリー | AI 推薦の理由が 3〜4 行で縦に長い | 理由は 2 行、根拠は 1 行までに省略表示。説明文も 1 文に |
| 診察サマリー | 症状の行がカード（囲いの入れ子 3 段） | 区切り線だけの行に（入れ子 2 段） |
| 在宅経過表 | 症状の行ごとに「患者自己申告」の小文字が重複 | 見出し行「自覚症状（自己申告 0〜4）」に集約し、行の小文字を削除 |
| 在宅経過表 | 表の下の注記が 2 つ（目安の全文＋自己申告の注意） | それぞれ 1 文に短縮 |
| 在宅経過表 | 表の値ボタンの高さ 30px | 32px に |
| 教材ライブラリ | 「セットから選ぶ」の外枠の中にカード（入れ子 3 段） | 外枠をなくしカードを直接並べる |
| 教材スタジオ | 手順の切り替えボタン 31px、「原文を表示」30px | 32px 以上に |
| 全画面 | 画面を切り替えても前の画面のスクロール位置が残り、見出しが固定ヘッダーの下に隠れる | 切り替え時に先頭へ戻す |

## 変えていないこと

- 医療者側の CTCAE の凡例と「正式な Grade 判定ではない」注意は残した（患者側では削除）。
- 診察サマリーは情報量が多い画面で、質問の原文・理解確認の設問・推薦理由など「説明文」として数えられる文字が 1,100 字前後ある。これは患者の記録そのものなので削らず、折りたたみ（AI 外来間サマリー）と省略表示（推薦理由）で初期表示を抑えている。
- 色: 医療者側は既存の落ち着いた配色（青緑の単色＋状態色）のままで、領域色は教材ライブラリのチップと処方状況のバッジだけに使っている。

## 点検の結果（最終）

`clinician_layout_audit.md` を参照。1180×820・820×1180 の 4 画面 × 6 状態で、はみ出し・重なり・小さいボタン・見切れは 0。囲いの入れ子は在宅経過・教材ライブラリで 2、診察サマリー（質問の番号の丸印）と教材スタジオ（図解エディタ）で 3。
