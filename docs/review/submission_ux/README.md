## 1. 医療費シミュレーター（`CostSimulator.tsx`・`social.css`）
- 入力: 「3/5　健康保険」の進捗と細いバー → いま答える質問 → 選択肢。適用範囲は 1 行で示し、長い説明は「対象条件を見る」を開いたときだけ（全手順の上部に長文を繰り返さない）。
- 「架空の例で試す」は最初の手順だけの副操作（手順の外）。その結果には「架空の例」バッジと「（架空の条件）」を表示し、最初から選び直すと解除。
- 医療費の入力: 見出し「保険診療の総医療費（10割）」・単位「円」・「窓口で支払った額（3割）ではありません」を入力欄のすぐ上に。「総医療費がわからないとき」を開くと領収書での確かめ方と確認・相談先。
- 結果の先頭: 対象月・「保険診療1か月分の自己負担の目安」・金額・解釈が変わる条件（所得区分・保険・総医療費（10割）・1 つの医療機関の外来か入院の一方・多数回該当）・確定した請求額ではない旨 → 主操作「医療費を変えて計算する」（直前の条件を引き継いで総医療費の入力へ）。
- 「計算条件・内訳」「対象外の費用・相談先」「制度と出典」は見出しから開く（内容は従来どおり）。
- 多数回該当が「わからない」: 「該当しない場合」「該当する場合」の 2 つの金額を最初から並べて表示。
- 対象外・所得区分や保険が不明: 従来どおり金額を出さず、理由と確認・相談先（推定の単一額は出さない）。

## 2. 医療者の診察サマリー（`ClinicianD.tsx` の `LiveIntervisit`・`demo-clinician.css`）
- 最初の画面の順序: 期間（実際の観察期間・前回共有日）→ サマリーの種類（1 行）→ 「患者が今日聞きたいこと」→「この期間の症状経過」→「理解につまずいたこと」。患者名・共有状態・残り時間・共有終了はヘッダーのまま。
- 患者の質問: 新しい順の 1 件を原文で先頭に（日付・種類・関連教材・「患者原文」）。複数は「ほか N 件」で開く。質問がない期間は「この期間に患者さんが残した質問はありません」。60 字を超える質問は 2 行で省略し「全文を表示」。
- 根拠: 各行のすぐ後ろに「根拠 N件」（重複した ID は 1 件として数える）。押すとその行のすぐ下に元の記録（日時・内容）。もう一度押すと閉じ、押した行が画面外なら元の位置に戻す。患者の質問の根拠は、その質問の元の記録だけ（ほかの質問を混ぜない）。
- 読み込み: 患者の質問の行は構造化データ（原文）だけで作り、AI 要約の読み込み・生成中の表示・代替表示は質問より下に置く（要約が届いても質問の位置が動かない。E2E で 2px 未満を確認）。
- 症状: 記録がない期間は「症状の記録はありません（記録なし。「症状なし」とは扱いません）」、記録があり程度がすべて 0 のときは「すべて0（なし・患者本人の評価）」と根拠。程度の数値の説明（患者本人の評価・CTCAE Grade ではない）を症状の行に置き、在宅経過表・症状のグラフへの導線を追加。
- 要約の全項目（18 項目など）・ルールベースへの切り替え・再生成は「要約の全項目」を開いたときだけ。サマリーの種類（Claude／記録済み出力の再生／構造化）・検証で除外した項目・代替表示の理由は従来どおり表示。要約の範囲の注意書き・カード（バイタル・自覚症状・学習・質問の原文）・統合タイムラインは変更なし。
- 教材スタジオ（承認と公開）は変更していない。
