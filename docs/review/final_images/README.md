### 修正（画像のためのレイアウト調整・1 点）
- 教材の詳細のサムネイルの枠が、画像を登録すると 4:3（約 290px）に広がり、「学習を始める」が 430px で画面の外に押し出された（画像なしでは画面内）。
- 主題が中央の帯（1600×470）に収まる新しい線画にだけ `band: true` を付け、教材の詳細では低い横長の枠（124px・内側の余白 6px。帯と同じ約 3.4:1）に切り抜いて表示する。画像なしの代替表示（96px）から 28px の増加。430px で「学習を始める」は画面内に戻った。主題が欠けないことを 3 教材で目視確認。
- 人物の入った既存のサムネイル（`band` なし）は従来どおり画像全体を表示（頭部が切れないように）。
- 390px の教材の詳細では、「学習を始める」は画像なしのときから画面の外（スクロールで表示）で、今回の変更による違いはない。
