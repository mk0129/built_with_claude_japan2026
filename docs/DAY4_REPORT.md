## 実装
| 区分 | 内容 |
|---|---|
| A 原資料・許諾 | PDF / Word / PowerPoint / txt（15MB まで）。非公開ストレージ（ローカル `private_storage/` または Supabase 非公開バケット）。許諾 5 項目（保存・AI 処理・改変・Web 公開・他施設共有）、許諾元・根拠・確認者・確認日時。個人情報なしの確認と正規表現検出（患者ID、生年月日、氏名欄、電話、郵便番号、メール）で AI 処理を停止。画像・低文字量ページの警告（OCR なし）。Claude 送信前とジョブ実行時の 2 回、サーバー側で許諾を確認 |
| B 生成 | B 方式（構成案 1〜3 → 選択 → 下書き）、C 方式（テーマ・対象・学習目標）。3〜5 画面、2〜5 問 3 択（「わからない」はアプリ側で付与）、正答・監修用解説・sourceRefs。原資料外の医学情報を追加しない指示、原資料は data として扱う指示。引用の実在チェック（不一致は警告）、形式違反は失敗。ジョブ化・進捗表示・再試行・冪等キー |
| C 編集・承認 | 原資料と並べて編集（引用の位置をハイライト）。下書き → 承認依頼 → 承認して公開 / 差し戻し（コメント）/ 公開停止。共通教材は作成者以外の運営承認者かつ他施設共有許可が必要。病院独自は所有組織の承認者なら自己承認可。未承認は処方候補に出ない。公開で既存の処方・学習・クイズに接続 |

画面: `/staff/studio`（一覧・登録）、`/staff/studio/sources/[id]`（許諾・抽出・生成）、`/staff/studio/materials/[versionId]`（編集・承認）。API: `/api/v1/studio/*`。DB: migration 0006（ローカル・Supabase 適用済み）。

## 実 API 検証の手順
1. `.env.local` に `ANTHROPIC_API_KEY=sk-ant-...` を追加（Git 対象外）。モデルは `CLAUDE_MODEL`（既定 claude-sonnet-5-5）
2. `CLAUDE_FAKE` なしで `npm run dev` を再起動（教材スタジオの黄色い「未設定」表示が消えることを確認）
3. `E2E_SHOT_DIR=docs/screenshots/day4_real npx playwright test studio -g 原資料`（デモ資料で C 方式生成 → 編集 → 承認 → 処方 → 患者表示）
4. 生成された下書きの変更履歴に「Claude（モデル名）による下書き」と表示されることを確認

送信されるのは原資料の抽出テキストと医療者が入力したテーマ・目標のみ。患者の自由記述・クイズ回答は送らない。
